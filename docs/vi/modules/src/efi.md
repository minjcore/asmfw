# efi.inc
[`src/efi.inc`](../../../../src/efi.inc) — 348 dòng, 0 entry point.

The UEFI ABI as this firmware implements it.

Structure offsets are written out as constants rather than built with a struct macro: these numbers are fixed by the specification, and having them visible is what lets them be checked against it.
