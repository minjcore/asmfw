# font.inc
[`src/font.inc`](../../../../src/font.inc) — 109 dòng, 0 entry point.

The console font, one 8x16 cell per printable ASCII character.

Generated by tools/mkfont.py; edit the source art there, not this file. Bit 7 of each byte is the leftmost pixel. Glyphs occupy columns 1..6 and rows 1..14, so adjacent cells never touch and descenders have room.

## Định nghĩa

Hằng số: 4.

Dữ liệu và state: `font8x16`
