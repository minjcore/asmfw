# acpi.asm
[`src/acpi.asm`](../../../src/acpi.asm) — 664 lines, 12 entry points.

QEMU's fw_cfg interface, and the ACPI tables behind it.

QEMU does not hand firmware a finished set of ACPI tables. It hands over blobs, plus a script — etc/table-loader — that says where each blob has to be placed, which pointers inside them to patch once the addresses are known, and which checksums to recompute afterwards.

| `acpi_init` | [96](../../../src/acpi.asm#L96) | run the loader script and publish the RSDP. Returns EAX = 1 if a configuration table was installed, 0 otherwise. Must run after efi_init: installing a configuration table rewrites the system table header, which does not exist until then. |

| `acpi_cmd_add_pointer` | [293](../../../src/acpi.asm#L293) | RBX = an ADD_POINTER command. The field at dest+offset holds an offset into the source blob; adding the blob's base turns it into the address the table is supposed to contain. |
| `acpi_cmd_add_checksum` | [362](../../../src/acpi.asm#L362) | RBX = an ADD_CHECKSUM command. ACPI's checksum rule is that the bytes of a table sum to zero modulo 256. The byte at `offset` is inside the summed range, so subtracting the sum from whatever is already there is what makes the total come out zero. |
